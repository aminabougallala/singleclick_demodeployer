# TechXchange 2026 hands-on labs

Three hands-on labs on **IBM watsonx.data integration**, each written as a
step-by-step guide with screenshots. Every lab runs in a TechZone
environment that is reserved for you; the reservation page provides the
sign-in credentials, and section 2 of each guide shows how to sign in.

| Lab | What you do | Duration |
|---|---|---|
| [LAB-3079: Agentic Data Observability](labs/dobs-lab.md) | Define alerts across a streaming job, a DataStage job and an Apache Airflow pipeline, receive them in the team's on-call channel, find the root cause with AI issue detection and fix each pipeline. | about 90 min |
| [LAB-1861: From Chaos to Clarity, Unstructured Data](labs/udi-lab.md) | Analyze and classify a folder of documents, add a custom document class, process the documents into tables and vectors, and query them in natural language. | about 90 min |
| [LAB-3106: Remote Engines](labs/remote-engines-lab.md) | Run a DataStage batch flow and a streaming flow on remote engines in your own environment while designing them from the cloud control plane. | about 90 min |

The guides are written for the lab sessions, but the environments they use
are the same ones IBM sellers reserve on TechZone, so they also work as
self-paced walkthroughs after the event while a reservation lasts.
